Portfolio site for Alex Kiersnowski. Next.js app with the home page, case studies, and a printable CV.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm run lint
```

Case-study copy and media live in `lib/projects.ts`. The CV is the static page at `public/cv`.
